# Nativa Rizada

Página web básica para mi emprendimiento de productos de cuidado para el cabello rizado importados desde Brasil.

## Propósito
Permitir a los clientes conocer los productos disponibles, leer algunas opiniones de compradores y enviar un mensaje a través del formulario de contacto.

## Tecnologías utilizadas
- HTML5 semántico
- CSS3 (Flexbox, Grid y Media Queries)
- Formspree para el envío del formulario
